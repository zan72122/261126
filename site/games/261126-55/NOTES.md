# ぬれたコンクリートに あしあと（261126-55）

霧の早朝、歩道の一枚分の木枠に生コンを流して、こてでならし、跡をつけ、乾かして歩道にする。
文字なし・指1本。iPhone / iPad の縦横対応。外部 CDN なし（three.js r180 を `vendor/` に同梱）。

## 遊びの流れ
1. **身じたく**：バケツの上のヘルメット、地面の長靴をタップ → 飛んで身につく（靴下の色→赤いゴム長靴に塗り替わる）。女の子が喜んでバンザイ。
2. **場面1 流し込み・こて**：ミキサー車のレバーを押している間だけドラムが回り、シュートが首を振って生コンが落ちる。
   落ちた所に山ができ、ビンガム流体ふう（降伏値つき）の流れでじわっと広がる。こてでなぞると
   ①山を均し（枠の上に余った分は進行方向へ運ぶ）②ざらざら（粗骨材の凹凸）が消え ③なでた回数ぶん鏡のようにつるつるになる。
   全体が満ち・平ら・つるつるになると完成（拍手）。
3. **場面2 跡つけ**：板の上の道具（こて／長靴／もみじの葉／恐竜の足型、何も持たなければ自分の手）を選び、押した場所に押した長さぶん深い跡。
   押したまま動かすと引きずり跡。跡の縁はわずかに盛り上がり、底には水が溜まって暗くつやが出る。
   3つ押すと、板を担いだパパがよそ見しながら看板（ぬれたコンクリートを靴で踏む絵に×）を無視して横断 → 大きな靴跡が並ぶ。
   パパ「あっ」→ 女の子「あれ？」の顔 → こてを指す白い手 → 娘が跡を消して直す → パパがグッ。さらに跡を押すと霧の中に太陽が出る。
4. **時間経過**：太陽をタップ（または待つ）→ 霧が晴れ、光が冷たい朝から明るい朝へ。コンクリートは縁と薄い所から斑に白っぽく乾く。型枠が外れて飛んでいく。
5. **場面3 歩道**：ママと犬も来て、跡の並んだ歩道で自由に遊ぶ。手形をタップ→女の子が手を重ねる、長靴跡→その上に立つ、
   恐竜の足跡→犬がくんくん嗅いでワン、葉っぱの跡→もみじが舞い落ちてぴったり重なる。他の場所→犬が走っていく。左上のヘルメットで最初から。

毎回、流れ方（ノイズ付きの堆積）・こてのなぞり方・押す場所/長さ/角度（毎回ランダムに少し回転）で仕上がりが変わる。失敗やゲームオーバーはない。

## 写実のためにやったこと
- **主役の素材をシミュレーションと描き込みで**：粗いグリッド（192×96：厚み・ざらつき・磨き・乾き・ブリーディング水）と
  細かいグリッド（1024×512：跡の高さ・跡の水）をCPUで計算し、毎フレーム DataTexture に書き込み。
  頂点シェーダで実際に面を変形、フラグメントで高さ場の差分から法線を作るので、跡・リム・骨材の粒・こての筋が光で見える。
- **濡れ→乾き**：濡れた面は暗い灰色＋クリアコート（水膜）。磨くほど粗さ 0.6→0.035 になり、
  **平面反射**（反射カメラで別レンダー、法線で揺らす）で空・女の子・トラックが鏡のように映る。乾くと粗さ0.93の粉っぽい白灰色、斑と骨材の跡が浮き、跡の底がわずかに暗く縁が白っぽく残る。
- **全部 PBR**：MeshStandard/Physical。テクスチャは Python(numpy) のスペクトル合成（FFT なので継ぎ目なし）で自前生成：
  木目（年輪・鋸目・節・コンクリはね）、砂利と湿った土、骨材入りコンクリの詳細、塗装金属の汚れ/垂れ/傷/コンクリはね、布の綾織り・ニット・肌の毛穴・毛流れ。
  ベース色・法線・粗さ・AO を持たせ、大きな単色面を作らない。外部画像サービス（Stability）はクレジット不足で使えなかった。
- **人はSDF彫刻**：カプセル人形をやめ、丸錐・楕円体をなめらかに融合したSDFから Surface Nets でメッシュ化（`tools/figgen.mjs`）。
  ひじ・ひざの布のしわ、袖口・襟・裾の布の厚み、ポケット、反射テープ、ゴム長靴の底、ポニーテールの髪束（溝つき）まで形で作る。
  頂点ごとに SDF からAO（脇・指の間・耳）とスキンウェイトを計算。頭身は実寸（女の子110cm・パパ178cm・ママ162cm）。
  目は虹彩の繊維・瞳孔・輪部をシェーダで描いた眼球にクリアコート、まぶた（まつげライン付き）が閉じ開き・視線追従。
  口と眉はフレームごとに作り直すメッシュで、笑う・口を開ける・「お」の口・「あれ？」の歪み・困り眉が実際に動く。肌はほお・鼻の赤み、色つきAOで透け感。
- **光**：霧の夜明け＝低い暖色の太陽（ソフトなVSM影）＋空のHDR風環境マップ（PMREM）＋三脚の作業灯（スポット、影付き）で主役と顔を照らし露出を確保。
  時間経過で太陽が上がり霧が薄くなり、環境マップを朝用に切り替え。ACES フィルミック＋sRGB、ごく弱いビネットとフィルムグレイン、浅い被写界深度（自作ポスト）。
- **実寸とカメラ**：型枠 1.4m×0.7m、2×4材、ドラム径2.2m、タイヤ径1m。カメラは人の目の高さ付近・35mm相当、場面ごとに自動で寄る。縦画面は横幅を詰めて縦を広く撮る。
- **粒子**：生コンの流れは毎フレーム作り直す放物線チューブ＋ノイズ変形、はねは大きさの揃わない塊（べき分布）が飛んで落ちて沈む。

## 判断メモ
- 女の子は手が届く側の枠の外にひざ立ちし、反対側を触ると**生コンを踏まずに枠の端を回って**移動する（パパの失敗との対比）。
- 跡の深さは押した時間で漸近（指数）、こてで消すときは通過量に比例して戻す。パパの跡の8割以上が消えたら「直った」。
- 重さ：内部解像度は fps を見て自動で下げる（30fps 以上を目標）。人のメッシュは量子化バイナリ（`tex/fig_*.bin`）で、女の子を先に読み、パパ・ママ・犬は後から。
- 開発用：`?dev&state=pour|pouring|rough|half|stamp|prints|papa|dry|walk` で場面へ直行（スクショ用）。
- 生成スクリプト：`tools/maketex.py`（テクスチャ）、`tools/figgen.mjs`（人・犬）。
