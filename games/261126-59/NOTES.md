# さびたロボット ぴかぴか (261126-59)

雨の日の屋根裏で、古いトランクから出てきた茶色くさびた小さなロボットを、女の子（プレイヤーの指）が
ワイヤーブラシと布でみがき、関節に油をさして動かし、最後は一緒に雨漏りと窓の手伝いをする 3 場面のゲーム。
文字・数字なし、指 1 本（タップ / 長押し / なぞり）だけ。

## 流れ
0. 着がえ: 木箱の上のつなぎと手袋をタップ → 女の子が着る（服・手袋が実際に替わる）。
1. トランク: 留め金をタップ → きしむ音でふたが開く → 中に寝ているロボットをタップ → 女の子が床へ抱え出す。
   みがき: ブラシでこすった所だけ、さびが粉と破片になって落ち（床に積もって残る）、くすんだ鋼が出る。
   布でこすると、さびを落とした所だけ鏡のように光り、窓と作業灯が映り込む。布は目・口のガラスのほこりも拭く。
   正面側の頂点の平均が「さび落とし>0.82・つや>0.62」でゴール → 目がちらっと点くが、関節が固くて動けない。
2. 油: 長押しした所に油が一滴ずつ落ちる。首・両肩・両股の関節に 3 滴ずつで、その部分から順に動き出す（きしみ音が減る）。
   全部動くと起動 → パパが大きな油缶で「手伝うよ」→ 注ぎすぎて床が油だまりになり、ロボットがつるつる回り出す（パパ「あっ」顔）。
   娘が布で油だまりを拭いた分だけ回転が遅くなり（ロボットを押さえても少し止まる）、止まると目を回したあと喜ぶ。
3. 窓辺: バケツをタップ → ロボットが雨漏りの下へ運ぶ → 窓辺によじ登って曇った窓を拭く。プレイヤーも窓をなぞって拭く。
   バケツが置かれ、窓が 6 割ほど晴れると雨がやみ、日が差して虹。以後は自由に遊べる
   （満杯のバケツをタップ → 捨てに行って戻る / ロボットをタップ → 踊る / 窓をなぞる）。

## 判断
- 「触った所だけが変わる」を最大にするため、ロボットの全金属パーツに頂点ごとの状態 (さび落とし, つや, 油) を持たせ、
  指の 3D 位置から半径内の頂点にだけ書き込む方式にした。UV の重なりに左右されず、道具・回数・順番がそのまま形に残る。
  ブラシは鏡面を傷つけてサテンに戻すので順番にも意味がある。さびの模様は毎回ランダムな位置ずらしで変わる。
- パパの失敗（油の入れすぎ）を「床の油だまりを拭く」という新しい触り方につなげ、娘が立て直す形にした。
- ルールは壁に立てかけた黒板 1 枚（チョーク絵: さびロボ→布→ぴかぴか、油缶→手をふるロボ、虹）。
- 迷ったら: 次に触る物がほのかに光り、4 秒触らなければ白い手が指さす（みがき中は一番さびている所）。

## 写実のためにしたこと
- テクスチャは画像生成 API が使えなかったので `tools/gen_tex.py` でスペクトル合成（タイル可能）した写真風の PBR セットを作成:
  床板・梁・板壁（木目、釘、すき間）、さび（色＋高さ/傷/汚れマスク）、つなぎの綾織り、ニット、革、ウール、段ボール、
  漆喰、肌の毛穴、髪の流れ、雨粒の法線、窓の外の景色。すべて color / normal / ARM(AO・粗さ) を持つ。
- ロボットの金属は MeshPhysicalMaterial を拡張したシェーダ: トライプラナーでさびの色・高さを貼り、
  「さびの厚み > こすった量」の所だけさびを残すので、境目が粉っぽく欠けた形になる。さびは粗さ 0.93・非金属・凹凸大、
  出てきた鋼はくすみ(粗さ 0.6, 茶色いしみ) → 磨くと粗さ 0.07 の鏡面＋細かい傷。油はクリアコートとして濡れたつやを足す。
  削れた量に応じて大きさのばらばらなさび粉/破片（インスタンス、陰影あり）が落ち、床に残る。
- 照明: 雨の日の屋根裏。窓からの 7200K の曇天光（ふちのぼけた影）、吊るした作業灯の 2900K スポット（影あり・フィラメントのゆらぎ）、
  半球光、屋根裏を簡略化した HDR 環境マップ（明るい窓・作業灯・梁）を PMREM で作り、磨いた鋼に窓と灯りが映る。
  雨上がりは光を 4800K に変えて強め、環境マップも作り直す。接地部にはコンタクトシャドウを敷いた。
- 後処理: HDR (HalfFloat, MSAA) → 半解像度ぼかし → 深度で少しだけ被写界深度、ACES フィルミック、sRGB、周辺減光、微粒子ノイズ。
- 人物: カプセルではなく、超楕円断面をロフトした胴（服のしわ入り）、2 ボーン IK で曲がる一本の管の腕と袖、
  手袋の指、彫刻した頭（ほお・鼻・唇・あご）、本物の眼球（虹彩テクスチャ＋クリアコート）とまぶた・まつげ、
  動く眉、表情で形が変わる口（キャンバス描画）、髪はキャップ＋100 本前後の房。表情は 10 種、まばたき・視線・声に合わせた口の動き。
- 実物大: 女の子 110cm、パパ 175cm、ロボット約 57cm、窓 90×100cm、トランク 78cm。カメラはひざ立ちの目線前後、
  縦画面は短辺 35mm 相当・横画面は約 45mm 相当で、要点が入る距離を自動で解く。
- 重さ: three.js と自作コードを esbuild で 1 本の ES モジュールに同梱（CDN なし）。スマホは DPR 1.6・MSAA 2 から始め、
  30fps を割ると解像度→被写界深度の順に落とす。テクスチャは並行読み込みで、くるくる歯車のあとに表示。

## ファイル

## 見直しと残っていること
- iPhone 縦横（390×844 / 844×390）と iPad 縦横（820×1180 / 1180×820）の画面をヘッドレス Chromium（ソフトウェア GL）で撮って確認し、
  鏡面が黒く映る（環境マップの読み込み順）、胴・手足の面の向きが逆、まぶたが目をふさぐ、髪が白く光る、口の画面が枠に埋まる、
  被写界深度のにじみ（手前の物のまわりの光の輪）、窓が真っ白、窓の場面でカメラが屋根の外に出る、などを直した。
- 自動操作で 着がえ→トランク→ブラシ→布→油（5 関節）→パパ→油だまりを拭いて停止→バケツ→窓ふき→虹 まで通ることを確認。
- 実機の iPhone では未計測。30fps を下回ると自動で解像度と被写界深度を落とす仕組みは入れてある。
- 人物の顔・髪は手続き生成の限界があり、写真そのものではなく「実写寄りの CG」程度。パパの顔は女の子ほど作り込めていない。
