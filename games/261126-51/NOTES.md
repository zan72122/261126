# 261126-51 こやを ぬろう（古い小屋のペンキぬり）

5歳向け・文字なし・指1本。春の朝、庭の隅の色あせた灰色の物置小屋を、自分で選んだ色のぴかぴかの小屋に塗り替える。

## 流れ（紙芝居ではなく、塗った場所・量・順番がそのまま残るシミュレーション）
1. **おきがえ** — 木箱の上の白い作業着（オーバーオール）と帽子をタップ → 画面の女の子が着る。ここから指は女の子の手。
2. **かべ** — 缶をタップで色、ローラー/刷毛をタップで道具。なぞった所だけ板がぬれた色に変わる。パパが横の壁を見本で塗りながら、得意げに振り向いて自分の鼻をローラーで緑にする（小ギャグ）。正面と横の壁が塗れたら次へ。パパも同じ色で横壁を手伝う。
3. **とびら・まどわく・やね** — パパがはしごに登り、吹き出しの絵で青い缶を頼む。缶をタップで手渡し（違う色だと「あれ？」の顔→笑顔）。パパが缶を倒して頭からペンキをかぶる → 木箱の布をタップ → カメラがパパの顔に寄り、指でこすった所だけペンキが取れて元の顔に（娘が立て直す）。その後、扉・窓枠・鼻隠し・屋根を塗ると完成。
4. **かわく→あそぶ** — タイムラプスで日が高くなり、つやが引いてマットに。チューリップの鉢と小鳥がやって来る。手形・花・葉・水玉のスタンプや刷毛で好きなだけ。小鳥は触ると飛び移り、鉢は揺れる。

失敗・ゲームオーバーなし。カメラは場面ごとに自動で寄る/引く。数秒触らないと白い手が次の場所を指し、塗り残しの板がかすかに光る。ルールは看板1枚の絵（灰色の小屋→刷毛→色の小屋）とパパの失敗で見せる。

## 写実のためにしたこと
- **すべて PBR**（MeshStandard / MeshPhysical）。木・屋根板・芝・コンクリ・布（綾織/天竺/平織）・肌・金属・素焼き・髪に、ベースカラー＋法線＋粗さ＋AO（ORM）を持たせた。写真風テクスチャは `tools/gen_textures.py` で手続き生成（文字・人物・ロゴなし。Stability API はクレジット不足で使えなかった）。
- **風化した板**：年輪ごとに幅と高さが違う晩材の稜線、浸食された早材の溝、干割れ、節、繊維。足元の泥はね・軒下のくすみをシェーダで足した。
- **ペンキの写実（主役）**：塗りは1024²のキャンバス・アトラス（色＋厚み）と256²の「ぬれ」マップに描き込む。シェーダは
  - 厚みが少ないうちは木目の稜線にだけ付き、往復して厚くなると溝まで埋まる（塗りむら→消える）。
  - 刷毛は毛筋のある型、ローラーは毛羽の点々の型をストロークの向きに回して押す。ペンキ量はストロークで減ってかすれる。缶を替えると境目で色が混ざる。
  - 塗りたては clearcoat＋低粗さで空と庭を映してぬれて光り、時間とともに場所ごとに乾いてマット（粗さ↑、clearcoat 0）になる。ペンキの厚みの勾配も法線に足し、溝の暗がり・割れ目のAOは塗っても残す。
- **光**：春の朝。低い太陽（約29°、約5000K）が左から壁をなめるように当たり、板目と目板の影が立つ。空ドーム＋ぼけた庭背景＋太陽から PMREM で HDR 風環境マップを作り、ぬれたペンキや缶・ガラスに映す。PCF ソフトシャドウ、足元・缶・小屋の接地暗がりデカール、ACES フィルミック＋sRGB。
- **大きさとカメラ**：扉1.9m、小屋の軒2.15m、娘1.10m、パパ1.75m。横長は約40mm、縦長は長辺基準で同等の画角、目の高さ付近から。背景はぼけた庭の写真風画像（浅い被写界深度の代わり）と霧で奥行き。
- **人**：カプセル人形にしないため、断面が楕円/超楕円の掃引面で胴・手足を作り、ひじ・ひざはボーン2本のスキニングで継ぎ目なく曲げる。頭は球を彫刻（頬・鼻・唇・あご・眼窩）、眼球は虹彩テクスチャ＋つやのある角膜、まぶた・まつげ・眉が動き、口は顔テクスチャに描き直して表情を出す。髪は束のリボン＋異方性ハイライト、服は織り目の法線としわの変位。
- **粒子**：ペンキのしずく（大きさ・速度ばらばら、速度方向に伸びる、地面で平たく）、光る粉、日差しの中の花粉。

## 重さ
- 最初の画面はテクスチャ読み込みを待たず2.5秒で表示（スタンドインで描いて後から差し替え）。three.js はリポジトリ内に同梱（CDNなし）。
- 1.5秒ごとのfps計測で描画解像度を自動で下げ/上げ（30fps以上を保つ）。

## 判断メモ
- 「指＝女の子の手」：指の位置に道具が出て、女の子はその近くへ歩いて腕を伸ばす。高い所は伸縮ポールが出る。
- パパの「ペンキかぶり」は顔テクスチャ上のペンキ層を、布で拭いた所だけ消す本物の拭き取りにした（壁塗りと同じ「触った所だけ変わる」）。
- 文字・数字は出さない。看板と吹き出しは絵だけ。
- 音はすべて WebAudio 合成（刷毛/ローラーのこすれ、缶、しぶき、小鳥、声、つま弾きの曲）。

## ファイル
- `index.html` / `js/main.js`（進行・入力・カメラ・粒子）/ `js/world.js`（庭・光・小屋）/ `js/paint.js`（ペンキの仕組み）/ `js/people.js`（人）/ `js/props.js`（小物）/ `js/audio.js`

- デバッグ: `?stage=walls|trim|dry|play`（途中から）、`?dtmax=0.25`

## 実画面での見直し（iPhone縦 390×844 / iPhone横 844×390 / iPad縦 820×1180 / iPad横 1180×820）
- 見つけて直したもの：窓の奥が真っ黒な穴に見える（小屋の芯の箱が窓をふさいでいた→窓の部分を開け、中の棚とガラスの映り込みを見せた）／ひじ・ひざが人形の関節に見える（スキニングで一続きに）／パーカー状の帽子のつばが額の棒に見える（前向きに曲げた）／横壁が見えない角度（カメラを右へ回して2面見せ）／縦長で小屋が切れる（縦向き専用の構図）／パパの拭き取りカメラが顔を外す（顔を毎フレーム追う）／ヒントの光が壁全体を白っぽくする（細いきらめきに弱めた）。
- 縦長のiPhoneは小屋全体を入れるため小さめに映る。缶や道具は小さいので、指の近く（短辺の7%以内）にある物はタップ扱いにした。
- まだ残る点：人物は実写寄りCGの質感まで寄せたが、近寄ると顔や手の造形は手作りCGの限界がある。ヘッドレス環境（ソフトウェア描画 4fps）では実機fpsを測れていないので、実機では自動解像度調整に頼っている。
