# かぼちゃのランタン（games/261126-58）

秋の夜、家族のハロウィン準備。字が読めない5歳の子が指1本で
「ただのオレンジのかぼちゃ → 暗い部屋に星や笑顔の光を映すランタン」を自分で作る。

## 遊びの流れ（場面は自動で寄る／切り替わる）
0. **帽子えらび** — テーブルの帽子（ニットのかぼちゃ帽・ねこ耳・魔女帽）をタップすると女の子がかぶり、その子の手が指になる。
1. **中身をかき出す** — ヘタを触るとふたが開く。口の中をなぞった所だけスプーンで果肉がはがれ（内壁の塗りマップ＋中身の塊の頂点が縮む）、指を離すたびにすくった量が種と一緒にボウルへ山になる。きれいになったら次へ。
2. **型でとんとん** — 星・丸・ハート・にっこり口の型を選び、皮をタップした場所に木づちで3回打つと穴があく（1打ごとに溝が深くなり、抜けると栓が転がる）。長押しでとんとん連打。
   2つ目の穴の後、**パパが特大の丸型で強く打ちすぎてぱかっと割れる** → テープが光り、割れ目を3回触ると女の子がテープで直す。直すと割れ目は細い光の線として残る。
3. **ろうそくと消灯** — ママが手を出して待つ。ろうそくを渡すと火をつけて中に入れる（スプーンや木づちを渡すと「あれ？」の顔→笑って戻す）。スイッチを押すと部屋が暗くなり、穴の形の光が壁・天井・人に映る。ランタンを指で回すと影絵が動き、暗い中でも穴を増やせて影絵が変わる。
4. **庭の小道（最後・好きなだけ）** — 戸口が光り、庭へ。家族のランタンを触ると灯る。灯ったものを触るとぱっと明るく火の粉、自分のランタンはくるっと回る、芝生を触ると落ち葉が舞う。

ルールは壁の黒板の絵（かぼちゃ→スプーンと種→星→ろうそく→光る顔）1枚。文字・数字なし。数秒触らないと白い手が次の場所を指す。失敗やゲームオーバーはなし。

## 写実のためにしたこと
- **素材はすべて PBR**。木目・漆喰・床板・ニット・リネン・タータン・クラフト紙・石・芝・板壁・肌・髪・かぼちゃの皮/果肉/わたの各テクスチャを、FFT ノイズで作ったタイル可能な写真風画像として生成し、ベースカラー・法線・粗さ＋AO の3枚1組にした（`tex/`、生成スクリプトは手続き的・文字や人物なし）。128px 版を先に読み、大きい版は表示後に差し替える。
- **かぼちゃは厚みのある殻**：外皮（物理マテリアル＋クリアコート）と内側の果肉殻の二重構造。穴はシェーダー内の形の距離関数で切るので、切り口のふち・皮の厚み・半分打っただけの溝が光で見える。同じ穴の判定をろうそくの**点光源シャドウ**にも使うので、穴の形どおりの光が壁や天井に投影される。炎の揺れで光源位置が数 mm 動き、影絵もゆらゆら動く。
- **かき出し**：内壁はわた（濡れて粗さ低い）と、かいた所だけ現れる果肉（乾いた明るい黄）をキャンバスの塗りマップで混ぜる。かき出した所は点灯後に少し透ける。中身の塊は頂点が縮み、種は数とサイズ・向きがばらばら。
- **照明**：ペンダント照明（約3000K、柔らかいPCF影）＋床置きランプ、夜の窓からの青い月明かり、環境マップ（光る小部屋から PMREM で作るHDR風）。消灯後はろうそく（約1800K）が主光源。暗くても顔が沈まないよう、ランタンから漏れる暖かい反射光・ティーライト・月明かり・露出の自動補正を入れた。
- **画作り**：HDR で描いて独自の最終パスで被写界深度（浅め）・ブルーム・ACES フィルミック・sRGB・周辺減光・粒子ノイズ。カメラは人の目の高さ、対角 57°（約 38mm 相当）。実寸（テーブル 74cm、子 110cm、ドア 2.05m など）。
- **人**：球を彫刻的に変形した頭（頬・鼻・あご・眼窩）、虹彩テクスチャ入りの眼球とまぶた・まつげ、太さの変わる眉、塗り直す口のデカール（笑う・開く・すぼめる）、束を重ねた髪、ニット/チェックの服は胴体を断面から作り、腕は毎フレーム作り直す袖（ひじのしわ付き）で IK。表情（にこ・わあ・あれ？・どや・しまった）と瞬き、視線。

## 判断メモ
- 画像生成 API はクレジット不足で使えず、全テクスチャを手続き生成にした。
- 3D 移動・カメラ操作はなし。指は画面内の物だけ。
- 毎回違う仕上がり：かぼちゃの形（うね数・高さ・傾き）は毎回ランダム、穴の位置・種類・順番は子どもが決める。
- 負荷：室内の月明かりは影なし、ろうそくの点光源影は 512〜768px、解像度は fps を見て自動で下げる（30fps 維持）。
- 外部 CDN なし（three.js r170 を `lib/` に同梱）。
