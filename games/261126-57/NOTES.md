# おまつりの わたあめやさん — 制作ノート

5歳の娘が iPhone / iPad で指1本で遊ぶ、文字のない 3D ゲーム。
夏祭りの夜、提灯の灯る屋台で、はっぴとはちまきを着けた女の子がわたあめを作る。

## 遊びの流れ（紙芝居ではなくシミュレーション）
- **はじまり**：フックのはっぴ／カウンターの丸めたはちまきに触ると女の子が身につける。両方そろうと提灯が太鼓に合わせて1つずつ灯り、屋台が開く。
- **場面1 はじめてのわたあめ**：色砂糖のびんに触る → 女の子がさじですくい、機械の頭に落とす（砂糖粒は1粒ずつ落ちる粒子）。熱で溶けた砂糖が細い糸になって鉢の壁へ飛び、鉢のふちに綿がたまる。棒立てに触ると棒が鉢に入り、指で鉢の中をなぞると棒が指についてくる。**なぞった長さの分だけ**鉢の綿が棒に巻き取られ、棒は回る。途中で別の色の砂糖を入れると、その時点から新しい色が外側に重なる。顔より大きくなると女の子が自分の顔の横に掲げて大喜び → 陳列台に立てる。
- **場面2 お客さん**：男の子・おばあちゃん・ママが順に来て、頭の上の吹き出しに「欲しいわたあめ」（大きさと色の層）が浮かぶ。吹き出しの中身も同じシミュレーションで実際に作った小さなわたあめ。できたらお客さんに触って手渡し。色や大きさが違うと「あれ？」と首をかしげてから、やっぱり喜ぶ（失敗なし）。
  - **パパのやらかし**（1人目）：パパが「まかせて」と受け取り、暑くてうちわで扇ぐ → わたあめが顔に張りつく → 濡れたおしぼりで拭いたらわたあめが濡れて**透明に溶けてしゅんと縮む**。戻ってきた縮んだわたあめを、娘がもう一度巻いて立て直す。パパの顔の綿は触るとちぎれて取れる。
- **場面3 花火**：夜空に花火（光が屋台と人を照らす）。わたあめは自由に作り続けられ、陳列台に触ると立てて並べられる。空に触るとその場所に花火が上がる。

## 「触ったところだけ変わる」の作り方（candy.js）
- わたあめは約3600頂点の球。**頂点ごとの半径**を持ち、綿は「棒の動いた向き＋鉢の壁から来る向き」にだけ積もる（棒の軸まわりのカーネル）。なぞる方向・長さ・回転で毎回違う形になる。
- **色の層**：頂点ごとに内側の色／外側の色／外層の厚みを持つ。色を替えると、そのとき巻いた側だけ新しい色が外を覆い、奥の色は芯越しに透けて見える。判定用に色ごとの体積も記録。
- **濡れ**：頂点ごとの濡れ量。濡れた所だけ半径が縮み、芯のシェーダで粗さ→0.1、色が濃く飽和、透明度が上がり、クリアコートが乗って「溶けた砂糖の飴」のつやになる。外側のふわふわ殻と糸はその部分だけ消える。新しく巻いた綿は濡れの上を覆う。
- 形はランダムな「もこもこ」の塊（16個のやわらかい山）＋細かいゆらぎで、毎回ちがう雲形になる。最初の小さいうちは糸が棒のまわりを一周するように広く付き、とがりすぎた所はならす。
- 色の境目は隣の頂点と少しずつ混ぜ、糸が交じり合う柔らかなグラデーションに。
- 大量の綿を一度に受け取っても形が暴走しないよう、表面積に比例した小刻みな付着に分割（テストで半径が 0.38m に膨らむ不具合を発見して修正）。
- 機械（machine.js）：砂糖の量→回転・熱（ヒーター帯が赤く光る）→糸の放射→鉢の壁の綿の量、が順につながったストック＆フロー。

## 写実のためにしたこと
- **すべて PBR**（MeshStandard / MeshPhysical）。木・布・砂利・金属・和紙・肌・髪・わたあめ繊維・砂糖結晶は `tools/gen_textures.py` で生成した写真風テクスチャ一式（ベースカラー／法線／AO・粗さ・金属の ORM パック）。木目と板の継ぎ目と擦り傷、はっぴ（藍染＋青海波）の織り目としわ、紅白幕の帆布、鉢の金属のヘアラインと傷、玉砂利、和紙の繊維、肌の毛穴。文字・人物・ロゴなし。
  - 画像生成 API（Stability）はクレジット不足で使えなかったため、テクスチャはすべて手続き生成。
- **照明は夏祭りの夜**：屋台の裸電球（3000K 前後）をソフトシャドウ付きスポットの主光源に、提灯（赤・生成り）を暖色の点光源、通りの明かりを前からの補助光、背後の屋台列の明かりを金色のリムライトに。空は濃紺。環境マップは「夜空＋周囲の屋台の灯り＋木の屋台内部」を HDR で組んだシーンから PMREM で作成し、金属の鉢やガラスびん、瞳に提灯が映る。ACES フィルミック＋sRGB。
- **露出**：夜でも顔と主役が沈まないよう、正面の補助光・肌の擬似表面下散乱（縁がほんのり赤く明るむ）・提灯の発光で見せ場を照らす。電球が頭のすぐ上で髪が白飛びした問題は、電球を前に出して光量を下げ補助光を上げて解決。
- **わたあめの写実の切り口**：
  - 数千本の砂糖の糸（線）を表面に巻き付け、糸ごとに視線とのなす角でリム光を計算 → 提灯の明かりで**ふちが金色に光る**。芯も縁ほど透けて糸だけが残るシェーダ、2枚の繊維アルファの殻でふわふわの輪郭。
  - 水に触れた所は**透明に溶けて縮む**（上記）。滴の粒子と「じゅっ」という音つき。
- **人**：カプセルではなく、超楕円断面のロフトで胴・腕・脚を作り、肩の傾斜・お腹のふくらみ（子ども）・布のしわを頂点で付けた。頭は顔の造形（頬・鼻・眼窩・あご）を彫刻した球。目は虹彩を描いた眼球＋クリアコート＋まぶた（瞬き・笑い目）＋まつ毛、眉・口（開き・笑み・「お」の口、歯と舌）が動く。髪は頭皮のキャップ＋束（前髪・ツインテール・おだんご・短髪）＋細いアホ毛の線（リム光で光る）。頭身は実寸（女の子 110cm で約5.6頭身、パパ 176cm）。
- **実寸と画角**：ドア/屋台の柱 2.35m、カウンター 80cm、女の子は木箱（30cm）に乗る。カメラは人の目の高さ付近、長辺 38mm 相当の画角で、場面ごとに自動で寄る（衣装→作る→掲げる→お客さん→パパ→花火）。縦画面は長辺が縦になるので同じ 38mm 相当で被写体が収まる距離を計算。
- **被写界深度**：背景の屋台通りは玉ボケを焼き込んだ遠景（ボケの縁が明るい実写的な円形ボケ）にし、ポストエフェクトを使わず軽量に「少しだけ浅い」見え方にした。
- 接地の暗がり：影に加え、びん・機械・棒立て・陳列台の下にぼかした接地影。

## 確認したこと
- iPhone（390×844）縦・横、iPad（820×1180）縦・横で、衣装・作る・掲げる・お客さん・パパのやらかし・花火の各場面をスクリーンショットで見直した。直したもの：電球の真下で髪が白飛び → 電球位置と光量、鉢が黒い鍋に見える → 金属の環境反射とメタルネス、屋台奥の真っ暗な布 → 生成りの布と棚の道具、わたあめが白く見える → 砂糖の色の彩度とシェル・糸の白い加算を削減、はっぴの柄が細かすぎて鎖帷子に見える → 柄の拡大、パパがおかっぱ頭 → 短髪の流し、顎を広く。
- 「子どもが光っている物・白い手の指す物だけを触る」自動プレイで、最初から花火の場面まで通し、ヒントが画面外を指して進めなくなる所（花火の場面の陳列台）を見つけて、カメラが自動で陳列台に寄るようにした。
- サムネイル（thumb.png）は実際のゲーム画面（女の子が顔より大きい3色のわたあめを掲げる場面）。

## 重さ・読み込み
- three.js r170 を同梱（外部 CDN なし）。テクスチャは 1px のプレースホルダで即描画を始め、JPG は後から差し替え（シェーダ再コンパイルなし）。
- 描画解像度は 1.5 倍から始め、2秒ごとに速さを測って 30fps を割りそうなら下げ、余裕があれば最大 2 倍まで上げる。影は主光源1灯のみ。点光源は主光源・提灯2・通り・花火の5つに絞った。

## 判断メモ
- 文字なしでルールを伝えるため、柱に「さじ→機械→わたあめ→にっこり顔」の絵看板。次に触る物はかすかに光って揺れ、数秒触らないと白い手が指さす（巻くときは円を描く）。
- 女の子は左手でさじ、右手で棒を持つ（2本の腕を IK で動かす）。
- 縦画面ではお客さんと鉢を同時に大きく映せないので、作っている間はカメラが鉢に寄り、注文の吹き出しが屋台の上に移動してついてくる。
- お客さんの判定は「色ごとの体積の割合」と「平均半径」。違っても必ず喜ぶ。
