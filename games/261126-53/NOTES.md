# かせきを ほりだそう（261126-53）

元ネタ：Diana and Roma 2026年10月の回（10/10 恐竜ジオラマが本物に＋10/17 恐竜の足跡）。
主役の素材は「砂・岩・骨」。ビフォー（ただの砂の地面）→ アフター（自分で掘り出して組み上げた恐竜の全身骨格）。

## 遊びの流れ（文字なし・指1本）
0. **着がえ**：キャンプ机の探検帽とベストをタップ → 女の子に飛んで着せる。両方着ると跳ねて喜び、発掘へ。
1. **発掘（真夏の真昼の発掘区）**：女の子が区画の奥にひざをつき、指＝彼女の手。
   - 砂をなぞる → 刷毛が触れた所だけ砂が払われる（なでた時間・速さ・回数に比例）。毛先の筋、刷毛の前に寄る小山、崩れて安息角で落ちる斜面、舞う砂粒が残る。
   - 岩のかたまり（3個）は刷毛では払えない（刷毛がすべり、女の子が「うーん」、小づちが揺れて光る）。布の上の小づちをタップで持ち替え、叩いた所からひびが広がり、数回で割れて破片が転がる。
   - 骨が半分以上見えると光る → タップで持ち上げて手前のシートへ。床（硬い地層）には恐竜の足跡が2つ隠れていて、出てくると女の子が驚き、タップすると自分の手を当てる。
   - 8つ（頭・首・背骨・肋骨・腰・尾・前脚・後脚）全部掘り出すとゴール。
2. **組み立て**：台と鉄の支柱、完成形を描いた絵の看板（ルールはこの1枚だけ）。シートの骨をタップすると、骨が1本ずつ順に飛んで支柱の上に収まり、置いた順に恐竜の形ができる。
   - 骨に似た棒と石がまぎれていて、渡すと女の子は「あれ？」と首をかしげ、笑ってぽいっと横に置く。
   - 4つ置いたところでパパが木箱を抱えて来て、シートにつまずいて転び、骨がばらばらに落ちる。パパは「おっとっと」→尻もち→照れ笑い。落ちた骨は光るので、娘がもう一度並べ直す（パパは横で拍手）。
3. **遊ぶ**：完成した骨格の横で、ジオラマの小さな恐竜3匹が動き出して歩き回る。砂をタップ／なぞるとそこへついて来て、足跡が砂に残り続ける。恐竜をタップすると喜んで鳴く。旗をタップすると別の場所を掘って次の恐竜（首長竜型⇔カモノハシ竜型）へ。骨格は展示台に残っていく（3体目からは古い台を入れ替え）。

失敗・ゲームオーバーなし。数秒触らないと白い手が次に触る物を指し、触れる物は日差しのきらめきで光る。

## 写実のためにしたこと
- **照明**：真夏の正午。太陽は高く（仰角約55°）、わずかに暖色の白（約5500K相当）。空と黄土色の地面を描いた HDR 風の空を PMREM で環境マップ化し、照り返しの環境光に使用。PCF ソフトシャドウ（撮影範囲に追従する 2048 影マップ）。ACES フィルミック（自前の合成シェーダ）＋ sRGB 出力、遠景は空気遠近（もや）。
- **レンズ**：対角 58°（35mm 判で約 40mm）固定、画面比に合わせて距離を決める。人の目の高さ（約1.0〜1.75m）から見る。被写界深度は深度バッファから CoC を出す軽い1パスぼかし。
- **素材（すべて PBR）**：砂・硬い地層・砂岩・化石骨・木・帆布・綿・デニム・肌・髪・恐竜の皮・金属のテクスチャを `tools/gentex.py` で生成（スペクトル雑音・周期ボロノイで継ぎ目なし）。各素材に色／法線／ORM（AO・粗さ・金属）の3枚。単色ベタの大きな面を作らない。
  - 地面は2スケール混合＋超低周波の色むらでタイルの繰り返しを隠す。
  - 岩は三面投影（triplanar）で伸びを防ぐ。
  - 化石骨は象牙色に茶色い染み・細いひび・繊維方向の凹凸。粗さは染みとひびで変わる。
- **触った所だけ変わる（ビフォー→アフター）**：
  - 砂は約8mm格子の高さ場（硬い床＋骨・岩の高さ＋その上の砂の厚み）。刷毛は楕円の当たり範囲で時間に比例して砂を減らし、毛束の周期で筋を彫り、一部を進行方向へ押し出し、安息角で崩す。頂点ごとに「砂の厚み・刷いたつや・掘り返し・接地AO」を持ち、シェーダで砂→地層の色、乾いた表面→掘り返した赤みの砂、刷いた所はつやが増し凹凸が細かくなる。骨や岩のまわりは周囲の高さから暗がり（AO）を計算。
  - 岩は叩いた点（物体座標）をシェーダへ渡し、3D セルノイズのひびが叩いた回数ぶん広がる。割れると破片が転がり、砂が流れ込む。
  - 展示前の砂地では小さな恐竜の一歩ごとに3本指の足跡を押し付け（中は締まってつやが出て、縁が盛り上がる）、消えずに増えていく。
- **粒子**：砂粒は大きさを2乗分布でばらし、色を6系統、太陽側が明るい小球として描く。地面に当たると止まる。土煙は柔らかいビルボードで光を受けて白っぽく。
- **人物**：カプセル組みをやめ、断面（幅・奥行き・超楕円）を補間して作った胴体と、肩〜手首・股〜足首を1本でつないだ腕脚を骨格スキニング。服は体と同じ骨で動く別メッシュ（Tシャツ、デニム、前あきのベスト＋ポケット、ブーツ・靴底・ひも）。頭は球を彫刻（頬・鼻・あご・唇の盛り上がり）し、眼球（虹彩テクスチャ＋クリアコートの濡れ）、まぶた（殻＋縁＋まつげ）、眉、唇（形を表情から毎フレーム生成）。髪は頭皮キャップ＋前髪シート（房先が不揃い）＋サイドの房＋揺れるおさげ、異方性ハイライト。5歳児（約110cm、頭身約5.4）とパパ（約178cm）。
- **大きさ**：骨格は全長約2.6m・頭まで約1.9m、発掘区は2m×0.8m、机・木箱・バケツ・杭なども実寸。

## 判断メモ
- 写真テクスチャの外部生成 API は使えなかったため、全テクスチャを手続き生成し同梱（約7MB、最初の画面は単色の仮テクスチャで即表示→後から差し替え。シェーダの再コンパイルは起きない）。
- 縦画面では発掘区が横に長いので、女の子の作業位置へカメラが自動で横に寄る。組み立て・遊びの場面は縦画面だけ斜めから撮って骨格を収める。
- 骨は発掘時、首と尾は「死んだときに丸まった姿勢」の弧に並べ、その他は川で流れ寄ったように平行に寝かせる（毎回ランダム）。組み立て時は骨1本ずつが自分の位置へ飛ぶので、置いた順に形が現れる。
- 重さ対策：描画解像度は画素数予算で決め、フレーム時間を見て自動で下げる。砂は変化した行だけ GPU へ送る。ヒット判定は砂だけ高さ場のレイマーチ。
- 外部 CDN なし（three.js r170 を同梱）。`site/` は触っていない。
