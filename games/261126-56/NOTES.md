# ぬのを そめよう（261126-56）

5歳の子が指1本で遊ぶ、文字のない「しぼり染め」ゲーム。夏の終わりの風の強い午後、庭の物干しの前で、
真っ白な綿のTシャツとハンカチをひもで縛り、藍とピンクの桶に浸し、物干しでほどいて模様を出し、家族に手渡す。

## 遊びの流れ（場面は3つ＋準備）
- **準備**：踏み台の上のエプロンと手袋が光る。触ると女の子が身につけ（エプロンが体に沿って現れ、手がゴム手袋になる）、以後は指が彼女の手になる（腕の2関節IKで、触った所へ手を伸ばす）。
- **場面1 しばる**：机の上の布を触った場所がつままれて円錐状に立ち上がり、ひもが巻かれる。同じ所を何度も触る／長押しすると巻き数が増える（最大4）。縛った場所・数・巻き数がそのまま防染マップ（白く残る輪と、ひだの放射状のすじ）になる。両方の布を縛って少し待つと次へ。
- **場面2 そめる**：布をつまんで桶に下ろす。布の「実際に液面より下にある部分」だけが染まる（布メッシュをUV空間に描いて浸かっている所を判定）。浸す長さで濃くなり、何度も浸すと重なる。藍は引き上げると黄緑→青へ酸化していく。ピンクと藍を重ねると紫に。染めた布はかごへ。
  - **パパのやらかし**：藍を一度引き上げた後にパパが来て、のぞき込んで台にぶつかり藍の桶をひっくり返す。しぶきがパパの白いシャツにかかり、緑のしみが空気で青くなっていく。娘が倒れた桶を起こし（タップ）、藍の素の瓶を長押しして注ぎ足すと解決。パパは自分のシャツも物干しに干す。
- **場面3 ほどく・かわかす**：物干しの結び目を触るとひもがほどけて飛び、束が開いて模様が現れる。ほどいた布は風で乾き、濡れ色→少し淡い乾いた色に変わり、軽くなって大きくはためく。布をタップすると風が吹く。
- **おわり（自由あそび）**：乾くと家族が並ぶ。布を人へドラッグして手渡すと、その人が着る（Tシャツ／シャツは上着に、ハンカチは首のスカーフに）。持ち主と違う物を渡すと「あれ？」の顔（首かしげ・片眉）をしてから笑う。全部渡すと家族で喜び、右上に「もういちど」ボタン。人や布を触ると反応し続ける。
- ヒント：次に触る物がかすかに光り（布は発光、人や桶には光の粒）、5秒触らないと白い手が指さす（ドラッグは移動して見せる）。失敗・ゲームオーバーなし。ルールは黒板の絵看板（白T→ひも→桶→模様T、エプロン・手袋・にこにこ）。

## 写実のためにしたこと
- **人物**：カプセルの組み合わせではなく、符号付き距離場（ロフトした胴体断面・テーパー付きの手足・楕円体の頬/あご/鼻/耳・指5本の手）をスムーズに合成し、マーチングキューブ→ポリゴン削減→SDF勾配で法線→焼き込みAO・頬の赤み・まぶたの陰り→骨からの距離でスキンウェイト、を Python（`tools/gen_people.py`）でオフライン生成。5歳児110cm・パパ176cm・ママ162cm の実寸と頭身。服もSDFのオフセット＋しわのノイズで厚みのある別メッシュ。髪は束の溝を彫った塊とおさげ（風とジャンプで揺れる）。
- **顔**：眼球（虹彩の放射繊維・瞳孔・強膜を描いたテクスチャ＋クリアコートで反射）、まぶた（球殻を回転してまばたき・細め）、まつ毛、眉（上げ下げ・ハの字・片眉）、唇（毎フレーム組み直す上下唇と口の中・歯・舌）で表情を作る。肌は三平面マッピングの毛穴バンプ＋シーン＋暖色の回り込み。
- **布（主役）**：ヴェルレ積分の布シミュレーション（伸びにくく縮みでたわむ綿、長距離拘束で伸び防止、濡れると重く風を受けにくい）。染料は布ごとのGPUフィールド（R=還元藍（黄緑）, G=酸化藍（青）, B=ピンク, A=濡れ）。液に浸かったテクセルだけ吸い込み、濡れている間は織り目方向に異方性でにじみ（防染で止まる）、空気で酸化し、風で乾く。描画はベール・ランバート式の減法混色、織りの谷に染料がたまる、濡れで暗く・つや（粗さ0.9→0.42）、薄い綿の透過（逆光で明るい）、すそ・縫い目・リブ襟のディテール、柔らかいしわの法線。
- **素材と光**：すべて MeshStandard / MeshPhysical。芝・敷石（砂粒・目地・苔）・木（木目・節・風化）・トタン桶（スパングル・傷・白さび）・羽目板・麻ひもを Python で手続き生成（albedo / normal / AO・粗さ）。夏の終わり午後の太陽（色温度4800K相当、仰角約38°）＋空と庭を描いた環境マップ（PMREM）、PCFソフト影（影カメラは見ている所に追従して解像度を確保）、接地部の暗がり（コンタクトシャドウ）。HDR描画→被写界深度（実寸の焦点距離計算）→明部のにじみ→ACESフィルミック→sRGB。
- **カメラ**：35〜40mm 相当（横画面は40mm、縦画面は35mm）、子どもと大人の目の高さ付近。場面ごとに自動で寄る／引く。縦画面では幅を詰めて今の作業を追う。
- **水と粒**：桶の液面は波動方程式の高さ場→法線マップ（浸すと波紋）。藍の液面には赤銅色の泡（藍の華）。しずく・しぶき・注ぐ流れは大きさの違う光る粒。
- **風**：強弱のある突風（植え込み・芝・おさげ・布が同じ風で揺れる）、虫の声と風の音。

## 判断の記録
- 外部の画像生成APIはクレジット不足で使えなかったため、テクスチャも人物もすべて手続き生成にした（文字・人物写真・ロゴなし）。
- 「触った所だけ変わる」ことを最優先に、布は画像の差し替えではなく、形（縛った所の立体）と染料場（浸かった所）の両方をシミュレーションにした。同じ操作でも縛る位置・回数・浸す深さ・時間・順番で毎回違う模様になる。
- パパのシャツは着ている服の材質と物干しの布で同じ染料場を共有し、しみが着たまま青く変わる→干す→最後にまた着る、がつながるようにした。
- 重さ対策：服に隠れる肌の三角形は生成時に削除、大人はポリゴンを減らし、女の子のデータだけ先に読み込んで最初の画面を早く出す（パパ・ママは後から）。フレームが重いと描画解像度を自動で下げて30fps以上を保つ。
- 外部CDNなし（three.js r180 を `vendor/` に同梱）。

## ファイル
- `index.html` / `js/*.js`：ゲーム本体（`main` 起動、`render` 後処理、`world` 庭、`people` 人物と表情、`cloth` 布と染料、`props` 小道具、`fx` 粒と液面、`audio` 合成音、`game` 進行）
- `assets/tex/`：手続き生成テクスチャ、`assets/people/`：人物メッシュ（`.bin`）
- `tools/`：生成スクリプト（`gen_textures.py`, `gen_people.py`, `sdf.py`）
- デバッグ用URL：`?skip=tie|dye|mishap|line|dry`（途中から）、`?cam=x,y,z,tx,ty,tz,fov`
